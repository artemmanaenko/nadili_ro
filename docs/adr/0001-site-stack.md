# 0001. Site stack

Status: Accepted (2026-11-12)

## Decisions

- **Generator: Astro Starlight.** Built-in i18n with fallback content and active development; Material for MkDocs is in maintenance mode.
- **Hosting: GitHub Pages via GitHub Actions** (`withastro/action`). Static output, no server to run; every merge to `main` redeploys.
- **One locale: Ukrainian.** Guides are published in Ukrainian only; source material in any other language is translated into Ukrainian by the contributing agent (see `AGENTS.md`). One language keeps search and navigation simple. Starlight i18n can be enabled later by adding locales and per-language folders.
- **Contribution rules live in `AGENTS.md`;** `CLAUDE.md` only imports it, so Codex and Claude Code read the same rules.
- **URL: `https://artemmanaenko.github.io/nadili_ro/`.** When a custom domain is attached, set `site` to it and remove `base` in `astro.config.mjs`.
- **Sidebar: autogenerated from `guides/`.** A new guide appears in navigation without a config change.
- **Theme: light only, warm palette with Inter and Cormorant Garamond** (`src/styles/theme.css`). One theme keeps the palette consistent; `ThemeProvider` and `ThemeSelect` are overridden to force light and hide the switcher.
