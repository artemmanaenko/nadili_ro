## How to add a guide

<Steps>

1. Create a `.md` or `.mdx` file in `src/content/docs/en/guides/`.

2. Add a title to the frontmatter:

   ```md
   ---
   title: Guide title
   ---
   ```

3. Open a pull request.

</Steps>

## Checklist

- [x] The title is clear
- [ ] Facts that change over time have sources
