## Перегляд сайту

На сайті немає реєстрації, форм збору даних, аналітики чи рекламних трекерів. Пошук працює у вашому браузері: запит не надсилається нам або пошуковому сервісу.

Сайт розміщено на GitHub Pages. GitHub отримує технічні дані з’єднання та зберігає IP-адреси відвідувачів для безпеки сервісу. Обробку цих даних, строки зберігання та міжнародні передавання описує [політика GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Позначки чек-лістів

Позначки чек-лістів зберігаються у вашому браузері в межах сесії поточної вкладки, зокрема під час оновлення сторінки. Сайт не надсилає їх нам. Браузер може відновити їх разом із відновленою сесією; очистити їх можна через налаштування даних сайту. Старі позначки, збережені попередньою версією сайту, більше не читаються; їх також можна видалити в налаштуваннях браузера.

## Листування

Якщо ви пишете на contacts@nadili.eu або privacy@nadili.eu, ми отримуємо вашу адресу та вміст листа через Zoho Mail. Використовуємо їх для відповіді, виправлення матеріалів і розгляду звернень про права. Підстава — законний інтерес підтримувати довідник і відповідати на звернення; для виконання обов’язків за GDPR — відповідний юридичний обов’язок.

За правилами поштових скриньок Nadili листування про підтримку видаляється під час щоквартального перегляду після 12 місяців від останнього повідомлення, звернення про права — після 24 місяців, докази інцидентів безпеки — після 60 місяців. Особисті дані з листа не призначені для публікації на сайті.

Zoho залучає компанії своєї групи та субпідрядників. За [політикою Zoho](https://www.zoho.com/privacy.html) обробка може відбуватися в ЄЕЗ, США та інших країнах діяльності провайдера; для міжнародних передавань він передбачає договори на основі стандартних договірних положень ЄС. Відомості про застосовні гарантії та їх копію можна запитати через privacy@nadili.eu.
