	PFA (Persoană fizică autorizată) — форма роботи на себе в Румунії, подібна до українського ФОП.
</Summary>

## Кроки

<Steps>

1. **[Зверніться в Aprobat](#заявка-в-aprobat).** Повідомте про українське громадянство, статус перебування та майбутню діяльність.
2. **[Передайте документи](#документи-для-сервісу).** Узгодьте вид діяльності й адресу PFA; сервіс підготує заяви.
3. **[Підпишіть і дочекайтеся рішення](#подача-й-результат).** Після схвалення отримаєте реєстраційні документи.
4. **[Підключіть SOLO](#solo-ведення-pfa).** Виставляйте рахунки й передавайте витрати та звітність через сервіс.

</Steps>

## Заявка в Aprobat

:::caution[Можлива відмова]
За досвідом спільноти, українцям реєструють PFA, але не в усіх випадках. Подання через посередника не гарантує схвалення ONRC.
:::

Відкрийте [сторінку реєстрації PFA в Aprobat](https://www.aprobat.ro/infiintare-pfa) або [форму зв'язку з консультантом](https://www.aprobat.ro/contact). Звертайтеся саме щодо **înființare PFA** — відкриття PFA.

У першому повідомленні вкажіть громадянство, назву документа про перебування в Румунії та послуги, які плануєте надавати. Наприклад: розробка програмного забезпечення для іноземного замовника.

Попросіть взяти вашу справу на реєстрацію та надіслати перелік документів. Окремий попередній запит до ONRC для цього маршруту не потрібен.

### Вартість

| Сервіс | Реєстрація | Як звернутися |
| --- | --- | --- |
| Aprobat | 499 лей + TVA (ПДВ), за тарифом сервісу | [Заявка або консультант](https://www.aprobat.ro/infiintare-pfa) |
| SOLO | Включена в абонплату 139 лей/місяць | [Vreau PFA cu SOLO](https://www.solo.ro/infiintare-pfa-pfi) |

Нижче — відкриття через Aprobat, потім ведення в SOLO. Для відкриття одразу через SOLO оберіть **Vreau PFA cu SOLO**, заповніть дані й завантажте запитані документи; сервіс підготує пакет для ONRC.

До оплати узгодьте повну суму: реєстрація, адреса PFA, переклади й подальше бухгалтерське обслуговування. Запитайте, що повертають у разі відмови ONRC.

### Чек-ліст

- [ ] **Назва документа про перебування** — тимчасовий захист або тип посвідки.
- [ ] **Опис роботи** — які послуги надаватимете та кому.
- [ ] **Контакт для відповіді** — email або телефон.

## Документи для сервісу

Передайте консультанту документи за його переліком для вашого статусу. Переклади замовляйте після узгодження їхньої форми.

### Вид діяльності

Опишіть свою роботу; разом із консультантом виберіть **CAEN Rev. 3** — коди видів діяльності, подібні до КВЕД.

Орієнтири з [офіційного класифікатора](https://www.onrc.ro/documente/anunturi/CAEN-Rev.3_structura-completa.pdf):

| Код | Діяльність |
| --- | --- |
| 6210 | Розробка ПЗ на замовлення |
| 6220 | IT-консалтинг і керування комп'ютерними системами |

Вибирайте код за послугами, які фактично надаватимете. Передайте диплом або інший документ про професійну підготовку чи досвід, який погодив консультант: Aprobat запитує таке підтвердження для PFA.

### Адреса PFA

Узгодьте **sediu profesional** — адресу реєстрації PFA. Для власної адреси потрібен документ про право користування приміщенням; [ONRC описує вимогу тут](https://www.onrc.ro/index.php/ro/inmatriculari/persoane-fizice/persoane-fizice-autorizate-pfa?id=1153).

:::note[Немає адреси]
Замовте у сервісу **găzduire sediu** — надання адреси для реєстрації. Узгодьте вартість, строк договору та отримання кореспонденції.
:::

### Чек-ліст

- [ ] **Паспорт** — копія для перевірки особи; формат погодьте з консультантом.
- [ ] **Документ про перебування** — тимчасовий захист або посвідка для розгляду вашого випадку.
- [ ] **Коди діяльності** — узгоджені CAEN Rev. 3.
- [ ] **Підтвердження підготовки або досвіду** — документ, погоджений із сервісом.
- [ ] **Документ на адресу PFA** — право користування приміщенням або договір на адресу від сервісу.
- [ ] **Переклади** — за погодженим переліком.

## Подача й результат

<Steps>

1. **Перевірте підготовлені документи.** Звірте ім'я, паспортні дані, адресу та коди діяльності. Назва PFA містить ваше прізвище, ім'я та форму *persoană fizică autorizată*.
2. **Підпишіть документи за посиланням від Aprobat.** Сервіс описує дистанційну перевірку особи й підписання без власного електронного підпису.
3. **Дочекайтеся подачі.** Попросіть номер заяви в ONRC і повідомлення про результат. На запит про додаткові документи відповідайте через консультанта.
4. **Збережіть отримані файли.** Після схвалення сервіс передає документи, видані ONRC.

</Steps>

:::caution[Строк розгляду]
Не плануйте початок роботи лише за датою подачі. Додаткові запити або відмова ONRC можуть змінити результат і строк.
:::

### Що отримати

| Документ | Для чого |
| --- | --- |
| Certificat de înregistrare | Свідоцтво про реєстрацію з CUI — податковим номером PFA |
| Încheierea registratorului | Рішення реєстратора |
| Certificate constatatoare | Підтвердження зареєстрованих даних про дозволену діяльність |

### Чек-ліст

- [ ] **Підписані документи** — збережені копії.
- [ ] **Номер заяви в ONRC** — для відстеження через сервіс.
- [ ] **Свідоцтво про реєстрацію** — certificat de înregistrare з CUI.
- [ ] **Рішення реєстратора** — încheierea registratorului.
- [ ] **Підтвердження діяльності** — certificate constatatoare.

## SOLO: ведення PFA

Використовуйте [SOLO](https://www.solo.ro/intrebari/ce-face-solo-pentru-mine) для рахунків, обліку витрат і податкової звітності. Реєстрацію можна пройти в Aprobat, а ведення PFA передати SOLO.

### Як підключити

<Steps>

1. **Створіть обліковий запис на [solo.ro](https://www.solo.ro/) й оберіть Am PFA** — «у мене вже є PFA». Оплатіть обраний абонемент.
2. **Завантажте реєстраційні документи:** **Documente → Acte înființare**. Додайте свідоцтво, рішення реєстратора й certificate constatatoare.
3. **Оформіть довіреність за зразком SOLO.** Для представництва перед ANAF (податковою службою) сервіс вимагає нотаріальну довіреність; передайте оригінали за його інструкцією. Нотаріус — окрема витрата.
4. **Узгодьте початок обліку.** Повідомте, з яких країн ваші клієнти. Попросіть підтвердити налаштування податкового обліку та e-Factura перед першим рахунком.

</Steps>

:::note[Уже працювали]
Передайте також попередню податкову декларацію, рахунки й документи про витрати за поточний рік. [Порядок завантаження в SOLO](https://help.solo.ro/hc/ro/articles/38343246761245-Ghid-complet-inregistrare-amPFA-pasi-si-documente).
:::

### Чек-ліст

- [ ] **Реєстраційні документи PFA** — завантажені в SOLO.
- [ ] **Нотаріальна довіреність** — за зразком сервісу.
- [ ] **Країни клієнтів** — для узгодження податкового обліку.
- [ ] **Попередня звітність і рахунки** — якщо діяльність уже вели.
