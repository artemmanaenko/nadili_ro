## Як додати інструкцію

<Steps>

1. Передайте агенту нотатки, чернетку або посилання на джерело. Матеріал може бути будь-якою мовою. Дайте агенту посилання на правила репозиторію. [AGENTS.md](https://github.com/artemmanaenko/nadili_ro/blob/main/AGENTS.md)

   Матеріал також можна подати через GitHub. [Створити issue](https://github.com/artemmanaenko/nadili_ro/issues/new)

2. Агент оновить наявну інструкцію або напише нову українською. Він запустить перевірки й відкриє pull request (PR) із джерелами.

3. Доручіть іншому агенту перевірити PR за правилами репозиторію й джерелами. Агент, який підготував зміни, опрацює зауваження.

4. Перевірте в попередньому перегляді, чи зрозуміла інструкція. Звірте її з актуальною практикою та джерелами.

</Steps>

Докладніше в [CONTRIBUTING.md](https://github.com/artemmanaenko/nadili_ro/blob/main/CONTRIBUTING.md).
