## Підстави перебування

| Підстава | Що перевірити |
| --- | --- |
| Тимчасовий захист (*protecție temporară*) | Чи підпадаєте під чинні категорії та умови для переміщених осіб з України |
| Робота (*muncă*) | Яка процедура діє для вашого статусу та які дії виконує роботодавець |
| Навчання (*studii*) | Документи від закладу освіти та умови для відповідної програми |
| Сім’я (*reîntregirea familiei*) | Статус члена сім’ї, спорідненість і відповідну процедуру |
| Комерційна діяльність (*activități comerciale*) | Вимоги до заявника та погодження бізнес-плану для візи |

:::caution[Підстава через SRL]
Посвідка за комерційною діяльністю потребує окремої заяви й погоджень. Перевірте в IGI умови для першої посвідки та для її продовження до реєстрації компанії.
:::
